🔍 GCP Console 검증용 통합 비교 SQL

BigQuery Studio에 붙여넣으면 서울 리전 3개 목적지의 건수를 한 번에 비교합니다.

SELECT '1. DTS (sendbird_dest_dts_kr)' AS solution, COUNT(*) AS row_count, MAX(created_at) AS latest_ts
FROM `test-sendbird-cross-region-cp.sendbird_dest_dts_kr.chat_messages`
UNION ALL
SELECT '2. Table Copy (sendbird_dest_copy_kr)', COUNT(*), MAX(created_at)
FROM `test-sendbird-cross-region-cp.sendbird_dest_copy_kr.chat_messages`
UNION ALL
SELECT '3. CRR (sendbird_dest_crr_kr)', COUNT(*), MAX(created_at)
FROM `test-sendbird-cross-region-cp.sendbird_dest_crr_kr.chat_messages`
ORDER BY solution;
